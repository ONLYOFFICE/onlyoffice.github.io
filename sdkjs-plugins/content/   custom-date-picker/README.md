# Custom Date Picker Plugin

A plugin for ONLYOFFICE Spreadsheet Editor that allows users to insert dates from a built-in calendar by double-clicking on a cell.

## Features
- Double-click on any cell to open a date picker
- Select a date from the calendar
- Insert the selected date into the active cell
- Supports date format YYYY-MM-DD

## Installation
Install directly from the ONLYOFFICE Plugin Marketplace.
