# Layout Panel

Layout Panel is a plugin for OnlyOffice Presentation Editor that gives quick access to common object layout controls without digging through editor menus.

## What it does

The plugin helps you adjust selected slide objects with a compact side panel that includes:

- size controls for width and height
- position controls for X and Y
- rotation control
- alignment actions for left, center, right, top, middle, and bottom
- distribution controls for multi-object layouts
- aspect ratio locking while resizing

## Supported editor

- Presentation / Slides editor

## Files

- `config.json` — plugin metadata and marketplace settings
- `index.html` — plugin panel UI
- `css/layout.css` — styling for light and dark themes
- `scripts/layout.js` — logic for object measurement and editing
- `resources/` — icons, screenshots, and marketplace assets

## Notes

This plugin is intended to make common layout tasks faster and more predictable when working with grouped objects on slides.
