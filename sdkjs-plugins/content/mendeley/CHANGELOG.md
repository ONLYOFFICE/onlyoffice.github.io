# Change Log

## 1.0.0

* Initial release.

## 1.0.1

* Add translations for Japan and Chine languages.
* Other improvements.

## 1.0.2

* Change resources for locales files.

## 1.0.3

* Add notification that this plugin doesn't work into desktop.

## 1.0.4

* Refreshed interface for better usability
* Fix issue with author name.
* Ability for users to upload custom citation styles.
* Add support for styles that inherit behavior from parent styles.
* Improved compatibility with MS Word.
* Ability to add prefix and suffix
* "Omit Author" feature
* Citation locators support: Added ability to include page numbers, chapters, sections, and other location references in citations
* Preserve formatting and editing of manual citations.
* Support for styles with footnotes and endnotes
* Improved handling of repeated citations (e.g., automatic `Ibid.` support).
* Ability to edit citations via the context menu
* Added bibliography formatting feature.

## 1.1.0

* Improved the styling of the bibliography.
* Add MEDLINE journal title abbreviation option.
* Add option to include URLs of paper articles.
* Add bibliography preview to the settings page.

## 2.0.0

* Fix the journal name being printed twice in citations and the bibliography: the journal and the series of a source now go to separate fields.
* Fix page numbers of journal articles missing from citations and the bibliography.
* Fix the plugin not opening in browsers and Desktop Editors without modern JavaScript support.
* Offer Serbian in Cyrillic and in Latin script instead of one Serbian entry.
* Fix switching a note style between footnotes and endnotes leaving the citations where they were.
* Fix the plugin asking whether to keep manual edits of citations nobody edited after a style change.
* Update the built-in citation styles and locales.
* Fix a built-in citation style failing to load when zotero.org cannot be reached: the copy shipped with the plugin is used.
* Fix scrolling the found sources: a touchpad scrolls them smoothly, the list stops following the pointer when the button is released outside the plugin, and further pages are requested only when you scroll.
* Open a found source and clear the selection with the keyboard.
* Translate the prefix, suffix and locator fields and the "Omit Author" option of a found source.
* Reorder the sources of a citation by dragging them in the citation editing window, and add "Keep sources sorted" to keep the order set by hand.
* Fix the other citations and the bibliography not being updated after sources were added to a citation, removed from it or reordered.
