# Changelog

All notable changes to PDF Bookmarks are documented here.

## 1.0.6 - 2026-08-23

- Added marketplace metadata, store icons, screenshots, help, and publisher information.
- Added release documentation and an explicit local-storage privacy note.
- Added marketplace packaging tests.
- Verified light, dark, and contrast-dark theme support.
- Verified persistent per-PDF bookmarks, including same-named PDF separation.

## 1.0.5

- Added a visible launcher on the Plugins ribbon and left sidebar.
- Added multi-scale light and dark icons.

## 1.0.0

- Added persistent named PDF page bookmarks.
- Added one-click navigation, rename, delete, and clear-all actions.
