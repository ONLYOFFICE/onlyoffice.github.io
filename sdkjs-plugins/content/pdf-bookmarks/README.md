# PDF Bookmarks

Save named page markers in PDFs and return to them with one click in ONLYOFFICE.

## Features

- Add a bookmark for the currently visible PDF page.
- Jump to, rename, or remove saved bookmarks.
- Keep a separate bookmark list for each PDF.
- Persist bookmark data locally between editor sessions.
- Follow ONLYOFFICE light, dark, and contrast-dark themes.
- Work offline without accounts, analytics, or network requests.

## Compatibility

PDF Bookmarks requires ONLYOFFICE Desktop Editors 9.4 or later and supports the
PDF editor in view and edit modes.

## Important storage note

Bookmarks are private, app-local navigation data. They are not embedded into
the PDF outline and do not modify the PDF file. Removing the plugin or clearing
the editor's local data can remove saved bookmarks.

## Use

1. Open a PDF in ONLYOFFICE Desktop Editors.
2. Open **Plugins** and select **PDF Bookmarks**.
3. Navigate to a page, enter an optional name, and select
   **Bookmark current page**.
4. Select a saved bookmark to return to that page.

## Manual installation

1. Download `pdf-bookmarks.plugin` from the latest GitHub release.
2. In ONLYOFFICE, open **Plugins > Plugin Manager > My plugins**.
3. Select **Install plugin manually** and choose the downloaded file.
4. Restart ONLYOFFICE if the plugin is not immediately visible.
