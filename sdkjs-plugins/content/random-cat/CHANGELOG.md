# Change Log

## 1.1

* Initial version.

## 2.0.0

* The plugin has been rewritten to work with the current plugin API.
* The picture is now really inserted into documents, spreadsheets and presentations.
* Added the picture preview, the "Another cat" button and the image size setting.
* Added support for the light and dark interface themes.
* Added translations: Russian, German, French, Spanish, Italian, Portuguese (Brazil), Czech, Chinese, Japanese.
* Added icons for all interface scales and the Plugin Manager card.
* Added loading and error states.
