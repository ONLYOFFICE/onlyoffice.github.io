Libraries inside opsin.jar (OPSIN 2.9.0, shipped unchanged as published by its author)

opsin.jar is a single runnable file that bundles OPSIN with the libraries below. Each keeps its own license.
opsin.jar is a separate program: Reactio Draw starts it with Java and talks to it through standard input and
output; it can be replaced by any other build of OPSIN.
