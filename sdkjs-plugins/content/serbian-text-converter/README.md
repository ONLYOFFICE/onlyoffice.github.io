# Serbian Text Converter

ONLYOFFICE plugin that converts selected Serbian text between Cyrillic and Latin. Open it from the side panel or from the right-click menu. It runs in documents, spreadsheets, presentations, and PDF.

## How to use

1. Select the text.
2. Open the plugin from the Plugins tab. The panel names the script and shows a short preview.
3. Click **Convert to Latin** or **Convert to Cyrillic**.

The same three commands are in the right-click menu, under **Serbian converter**:

- **Cyrillic → Latin**
- **Latin → Cyrillic**
- **Automatic swap** — uses the script of the selection

**Keep foreign words and brands unchanged** is on by default. Words that are not Serbian stay in Latin. Turn it off to transliterate every word.
