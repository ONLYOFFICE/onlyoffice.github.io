# Change Log

## 0.1.0

* Initial release.
* Checks paper size, margins, font family and legacy Vietnamese font encodings, text colour, font sizes, and the national title and motto against Decree 30/2020/ND-CP, Appendix I.
* Reports a note instead of a result when the editor cannot supply a value (for example page margins in ONLYOFFICE 8.3.3).
